### 🔐 Privilege Escalation

### 📌 What is Privilege Escalation?

Privilege Escalation is a cybersecurity concept where an attacker or user gains higher access permissions than originally granted.

It usually happens when a system has security misconfigurations, weak permissions, or vulnerabilities.

---

### 🐧 Linux Privilege Escalation

Important areas to check during authorized security assessments:

- SUID / SGID Permissions
- Sudo Permissions
- Cron Jobs
- Writable Files & Directories
- Linux Capabilities
- Running Processes
- Kernel Vulnerabilities

---

### 🪟 Windows Privilege Escalation

Important areas to understand:

- User Privileges
- Windows Services
- Unquoted Service Paths
- Weak File Permissions
- Scheduled Tasks
- Registry Permissions
- AlwaysInstallElevated

---

### 🛡️ Prevention

- Apply regular security updates.
- Follow the Principle of Least Privilege.
- Use strong authentication.
- Review file and directory permissions.
- Disable unnecessary services.
- Monitor system activities.
- Regularly audit user privileges.

---

### ⚠️ Disclaimer

These notes are for educational purposes and authorized security testing only. Never attempt privilege escalation on systems without permission.
